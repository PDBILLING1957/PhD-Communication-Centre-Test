Backup / Device Transfer

Export a complete JSON backup on one device, transfer it using AirDrop / Files / cable, then import on the other device. Import merges records by permanent ID, blocks conflicting or duplicate records, and does not overwrite existing data. This is manual transfer, not live sync.

Data maintenance

Important limitations

  • Data remains in this browser on this device unless exported.
  • Background sync between iPhone and iPad is not implemented in this build.
  • WhatsApp handoff only opens a prepared chat; you must press Send yourself.
  • Delivery/read receipts are not available to this app through ordinary WhatsApp handoff.
  • Business-card OCR and automatic WhatsApp history import are not included.
  • GPS requires your permission and may be unavailable indoors.
  • Road routing and live traffic are not built in; map directions open in an external map service.
